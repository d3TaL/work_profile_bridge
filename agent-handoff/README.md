# Profile Link Bridge — комплект для агента

Дата: 18 октября 2026. Документы составлены по переписке владельца. Это задание на разработку, а не исходники приложения и не готовый APK.

## Как использовать

1. Откройте существующий Android-проект в среде агента. Предпочтительная исходная версия: `profile-link-bridge-0.1.1-recovered-tls.zip` или её git-репозиторий.
2. Скопируйте этот комплект в отдельную папку `agent-handoff` внутри проекта. Не перезаписывайте существующий AGENTS.md без чтения и согласования применимых правил. Из данного AGENTS.md перенесите необходимые проектные инструкции.
3. Передайте агенту содержимое [AGENT_PROMPT.md](AGENT_PROMPT.md). Промпт работает и при размещении комплекта в корне проекта.
4. Начните с P0 из [IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md): улучшить диагностику и получить воспроизводимый результат на устройстве.

Если старых исходников нет, агент может создать новый минимальный проект, но обязан обозначить это как новую реализацию. Старая debug-подпись и прежние результаты тестов автоматически не восстанавливаются.
