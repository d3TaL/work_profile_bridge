# План реализации

## P0 — диагностическая сборка

Проверить реальный checkout; найти skills и инструкции; сохранить baseline без приписывания старых тестов. Разделить причины и этапы по DIAGNOSTICS. Добавить self-check, безопасный отчёт, видимый срок listener и корректную отмену. Проверить отсутствие токена в отчёте и отсутствие fallback. Собрать APK, дать SHA-256 и один сценарий владельцу. Результат: причина следующего теста наблюдаема, а не угадана.

## P1 — разрешённый транспорт

На основании официальных API и физического отчёта описать ADR по work profile и отдельно Secure Folder. Зафиксировать необходимые DPC policies, разрешения, user actions и ограничения. Localhost на Android 17 не выбирать автоматически. Если реального разрешённого пути нет, сохранить диагностику и явно отключить неподдерживаемую функцию. Не добавлять бессмысленный background listener для недоступного транспорта.

## P2 — постоянное доверие

Реализовать подтверждение пары, идентичности обеих сторон, отзыв, reinstall/rotation, защищённое хранение. Негативные тесты чужой пары/подмены/отзыва обязательны. Временный диагностический token не превращать в долгоживущий ключ.

## P3 — доставка безопасного URL

Отдельный versioned protocol или разрешённый системный канал; независимая валидация receiver-side, TTL, дедупликация, bounded queue и UNKNOWN_OUTCOME. Сначала только публичные синтетические HTTPS URL. Не повторять автоматически после неясного результата запуска.

## P4 — открытие целевого приложения

Пользователь выбирает пространство и разрешённый пакет. Получатель подтверждает открытие; если UI не может открыться по правилам ОС, показывает разрешённое уведомление или ручное действие. Ozon/каждый банк подключать по документированным ссылкам и фактическому пакету. Проверить callbacks отдельно. Для реальных токенов не сохранять примеры в репозитории.

## P5 — качество и выпуск

Device matrix Android 11–17, unlocked/locked, paused work profile, process death, VPN, rotation, background, battery restrictions. R8 Release, lint, dependency verification, 16 KiB native compatibility, signing, reproducible instructions. Измерить battery/latency только после работающего сценария; не заявлять эффективность без измерений.

Каждый этап заканчивается commit, changelog, docs/VALIDATION.md и списком реальных ограничений. Отчёт с телефона является внешней зависимостью: при его отсутствии закончить доступную реализацию и тесты, не имитировать физический результат.
