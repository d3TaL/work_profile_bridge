# Требования

## Пользовательские сценарии

1. Пользователь делится поддерживаемой HTTPS-ссылкой с мостом, выбирает целевое пространство и разрешённый обработчик.
2. Получатель самостоятельно проверяет ссылку и правила, затем предлагает открытие внутри своего пространства.
3. Если профиль выключен, папка заблокирована, приложение отсутствует или переход запрещён политикой — мост объясняет наблюдаемое состояние и предлагает допустимое ручное действие.
4. Пользователь может проверить доступность пары, отозвать доверие и удалить ожидающие ссылки.
5. При неоднозначном результате мост не повторяет автоматически банковское действие.

## Границы

Один APK с отдельной установкой/данными в пространствах — предпочтение. Наличие одинаковой подписи не отменяет системную изоляцию. Work profile и Secure Folder имеют независимые capability results. Состояния: SUPPORTED, BLOCKED, UNAVAILABLE, UNKNOWN; NOT_TESTED не заменять на SUPPORTED.

MVP принимает только явно разрешённые HTTPS URL. Конкретные домены, пакеты и app links Ozon/банков проверять отдельно, не угадывать package name. Custom schemes и callbacks — отдельная задача после исследования и threat model. Не объявлять app links verified для чужих доменов без их domain association.

По умолчанию без cloud relay, root, смены DPC, обхода Knox, рекламы, трекинга и чтения банковских данных. Полный список установленных приложений не запрашивать; использовать минимальную package visibility.

## Критерии готовности

| Этап | Обязательное доказательство |
| --- | --- |
| Диагностика | Видны этап и безопасная причина, local self-check, обе стороны теста, отмена/expiry |
| Транспорт | Физическое устройство, точное направление, профиль, разрешения и воспроизводимый отчёт |
| Доверие | Подтверждение пары, отказ чужому peer, отзыв, переустановка, ротация |
| Доставка | Политика получателя, TTL, ограниченный размер, дедупликация и UNKNOWN_OUTCOME |
| Открытие | Пользовательский жест, выбранный пакет, проверка lifecycle, корректный отказ |
| MVP | Ссылка действительно открылась нужным приложением в нужном профиле на проверенной конфигурации |

Собранный APK и успешный TLS ping сами по себе не выполняют критерии MVP. Универсальная поддержка Android 11–17 не является допустимым заявлением до матрицы устройств.
