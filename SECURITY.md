# Уязвимости

Диагностический прототип не предназначен для настоящих банковских URL. Приватный канал отчётов пока не выбран владельцем. Не публиковать реальные ссылки, token, pairing code или банковские данные в issue. Использовать синтетический пример и версию прошивки/приложения.

Модель угроз: [docs/SECURITY.md](docs/SECURITY.md). Применённые меры: [docs/SECURITY_ALIGNMENT.md](docs/SECURITY_ALIGNMENT.md). Сборка без ошибок не заменяет аудит.
