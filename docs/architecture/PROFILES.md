# Пространства и сопряжение

Типы: Personal, ManagedWork, SamsungSecureFolder, Unknown. Пользовательская метка не даёт прав и не доказывает тип контейнера. Android userId не считать постоянным идентификатором.

Текущая TLS-идентичность — локальный EC ключ в AndroidKeyStore. Pin — SHA-256 всего leaf certificate. При истечении срока сертификата перед новой сессией создаётся новая локальная идентичность; прежние коды перестают подходить.

Сессия PLB2 содержит порт, pin и 256-битный bearer token. Пользователь переносит её из доверенного экрана получателя. Подмена кода подменяет выбранного peer: TLS не исправляет компрометацию канала, через который сам пользователь получает pin. Не передавать код третьим лицам.

Постоянное сопряжение, двухстороннее подтверждение, отзыв доверия, хранение peer credentials и защита восстановления из backup остаются следующей задачей. Текущий токен живёт только до закрытия/истечения сессии.
