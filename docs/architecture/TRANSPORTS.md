# Транспорты

Work profile: исследовать CrossProfileApps и разрешённые DPC intent filters. CrossProfileApps запускает свою копию, а не произвольный чужой пакет. Передача Intent требует доступного профиля и необходимых разрешений/allowlist. Наличие API не доказывает право перехода.

Secure Folder: публичный поддерживаемый способ доставки пока не подтверждён. Android 17 запрещает межпрофильный loopback по умолчанию независимо от targetSdk. Портовый мост нельзя выбирать базовым транспортом для основного устройства. На старых Android доступность требует проверки OEM/DPC. Новый диагностический канал использует TLS 1.3 и pin; bind/connect строго 127.0.0.1. Порты назначает ОС, сканирования сети/портов нет. Успех внутри одного профиля не означает доступность между профилями. См. [совместимость](../COMPATIBILITY.md).

Shizuku остаётся необязательным исследуемым адаптером; его наличие и работа cross-user на устройстве не подтверждены. Не собирать shell-команды с пользовательским URL.

Нет cloud relay, clipboard-шины, root или фиктивного FGS type. Переключение транспорта после неизвестного результата запуска запрещено без установления статуса.
