# Ссылки и маршруты

SafeLink принимает только HTTPS DNS URL с портом 443/default. Запрещены userinfo, IP/localhost, malformed escapes, controls, backslash, whitespace и слишком длинная строка. Unicode hosts пока только в ASCII/IDNA-представлении. Сравнение host без регистра, raw path с регистром. Original передаётся без перекодирования query/fragment и сортировки параметров.

RouteResolver: точный host → наиболее длинный raw path prefix → priority. Поддомены только на границе точки. При равенстве нужен выбор пользователя; порядок записей не влияет.

Редактирование правила не меняет manifest уже установленного APK. Чужие домены требуют осознанной настройки открытия ссылок, приложение не контролирует их assetlinks.json. Короткие ссылки не раскрывать сетевым запросом автоматически.

На получателе повторить проверку, проверить пакет и доверенную подпись, создать новый ACTION_VIEW с ограничением package. Не копировать flags, extras, ClipData или component входящего Intent. Нет handler — ошибка, а не автоматический браузер/другой профиль.
