# Жизненный цикл

Доставка TLS и возможность показать Activity независимы. Видимый отправитель не делает видимым получателя другого профиля. FGS сам по себе не разрешает запуск из фона.

Диагностическая сессия запускается вручную, живёт максимум 120 секунд, закрывает sockets при отмене/завершении. Приложение не обещает пробуждение по TCP, выживание после force-stop или доступ к заблокированной папке.

Для URL в будущем: локальный допустимый запуск либо уведомление с immutable PendingIntent прямо в собственное Activity; только непрозрачный requestId в extras, без URL. При нажатии повторить TTL/политику. Если уведомления запрещены, вернуть USER_ACTION_UNAVAILABLE, а не AWAITING_USER.

Выбор законного FGS type и background-режима требует отдельного ADR и проверки targetSdk. WorkManager не является постоянным сервером. Не использовать overlays/accessibility для обхода правил.
