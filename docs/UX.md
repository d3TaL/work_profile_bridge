# Интерфейс

Экран содержит три независимых теста: доступные CrossProfileApps копии; TLS сессия; локальная HTTPS-ссылка и обработчики. Ошибки не раскрывают исключения с чувствительными значениями.

«TLS-тест прошёл» означает pin+token+ACK, не выполнение оплаты. «Запрос открытия передан Android» означает только успешный вызов запуска. Timeout: «Получатель недоступен», без выдуманной причины блокировки.

Код можно выделить вручную, он не копируется/не передаётся автоматически. Во время client ping поле очищается. После завершения listener код убирается. Это временная диагностическая сессия, не постоянное сопряжение.
