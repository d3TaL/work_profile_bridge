# Интерфейс

Цель: человеку без технических знаний хватает одного выбора и чек-листа.
Тексты короткие, подробности — одной строкой под «Как?».

## Основная копия

«Куда отправлять ссылки»:

| Выбор | Что делает | Флаги маршрута |
| --- | --- | --- |
| Рабочий профиль | Ссылка сразу уходит в копию Shelter/Island | auto-forward, без share-route |
| Secure Folder | Сразу открывается «Поделиться», пользователь выбирает Bridge в папке | auto-forward + share-route |
| Спрашивать каждый раз | Две кнопки (без Samsung — одна) | без auto-forward |

Приложение с режимом «С подтверждением» (банки по умолчанию) всегда ждёт кнопку.
Старые настройки переносятся: ручной режим → «Спрашивать».

Чек-лист зависит от выбора: копия Bridge в рабочем профиле и связь с ним
(CrossProfileApps), Bridge в Защищённой папке (Bridge проверить не может —
«проверьте сами»), разрешённые домены «Открывать по умолчанию» (Android 12+).
Кнопка показывается, только если действие сейчас выполнимо.

## Копии-получатели

Пространство (рабочий профиль / Secure Folder) определяется ролью Android и
меняется вручную. «Открывать сразу» в Secure Folder включается только после
отдельного согласия: «Поделиться» там не аутентифицировано. При смене на
рабочий профиль автооткрытие публичного «Поделиться» выключается.

## Честность состояний

«Отправлено в рабочий профиль. Проверьте…» — Android принял запрос, доставка не
подтверждена. «Запрос на открытие отправлен» — только вызов запуска. Под меню
«Поделиться» — «Bridge не видит, что выбрано». Повторы не автоматические.
Ссылка не сохраняется в состоянии экрана, отчёте и журналах.
