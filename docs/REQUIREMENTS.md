# Требования

Цель MVP: нажатие поддерживаемой ссылки → мост снаружи → заданное пространство → выбранный Ozon/банк внутри. Work profile и Secure Folder могут существовать одновременно, маршрут выбирается явно. Приложение не меняет администратора профиля и не обходит блокировку.

Входы: согласованные HTTPS intent-filters, ACTION_SEND text/plain и ручная вставка. Текущая диагностика включает только два последних; автоматические App Links пока не зарегистрированы. Для чужих доменов нельзя обещать autoVerify.

MVP требует постоянного доверия peer, локальной политики разрешённых пакетов/доменных правил, TTL, дедупликации, безопасных уведомлений и честных статусов доставки/запуска. Всё это не считается реализованным одним успешным TLS ping.

Не входят: автоматическое подтверждение платежа, передача произвольного Intent, облачный relay, root, Accessibility/overlay-обходы и обратный банковский callback без отдельного проекта совместимости.
