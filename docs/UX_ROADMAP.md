# Порционный UX выпуск

## 0.4.2 — базовый пошаговый мастер

Четыре шага Back/Next, saveable только шаг/choice. Пресет сохраняется без
закрытия. Роль выделена, remote targets не объявляются work без сведений.
Samsung инструкция не равна обнаружению Knox. Его выбор остаётся ручным.
Android access прежним consent flow; app-link settings своей копии публичным
Settings API 31+ либо application details 30/fallback, без новых permissions.
Тест подставляет публичный root Ozon в поле без запуска. Завершение сохраняет
факт прохождения, не ложный PASS доставки. Входящие Intent не ждут мастера.
Банковская автоматика отдельно в Apps; настройки ссылок других пакетов далее.

## 0.4.0 — банковская автоматика и сохранение отчёта

По запросу владельца банковский AUTOMATIC доступен после отдельного диалога
на выбранную группу. Default CONFIRM. Sender auto-forward + bank AUTOMATIC;
receiver auto-open + bank AUTOMATIC. Knox ещё требует public SEND opt-in,
выбор получателя chooser остаётся ручным. Нет retries/банковского retryLink.
Protected TTL/replay сохраняются. Public SEND не аутентифицирован.
Первый совместимый пакет выбирается вне main, LocalLinkLauncher проверяет
его ещё раз перед новым VIEW/RESUMED. Это не подтверждение оплаты/callback.

Сохранение отчёта после просмотра через CreateDocument: snapshot только
в памяти, IO запись, без storage permissions/URL/секретов; process death
не восстанавливает snapshot, отмена/результат очищают его.

## 0.3.5 — правила приложений

Ozon/Wildberries из существующего реестра, не список установленного ПО. Поиск,
выбор одного/нескольких/всех найденных, bulk mode. Default AUTOMATIC сохраняет
прежнее поведение, сам не включает routing toggles. CONFIRM оставляет только
ручные действия, DISABLED запрещает известный магазин. Настройки локальны;
политики получателя проверяются независимо от отправителя. Банки не добавлены.
Групповой выбор назначения/undo и расширение реестра — следующие этапы.

## Порция 3b — 0.3.4: упрощение главного экрана

Карточка текущей роли/выбранного назначения, кнопка мастера, поле ссылки.
Маршрутная ручная отправка и локальные обработчики показываются при ссылке.
Routing toggles в раскрываемом Advanced, device/debug/report — Diagnostics.
Раскрытие сохраняется как boolean, URL не сохраняется. Ошибки не скрыты.
Список приложений/групповые правила и удаление TLS инструментария — далее.

## Порция 3a — 0.3.3: назначения и пресеты

Main: выбор конкретного target или Knox Sharesheet, включает auto-forward,
отключает local auto-open. Managed: receiver preset включает protected open,
выключает forward/public open. Samsung не-main: ручное подтверждение Knox и
public share согласия, включает только local public open. Manual выключает
всю routing автоматику. Compact/debug не меняются. Применение явной кнопкой,
ручные markers сохраняются; при refresh route не подменяется. Remote target
назван копией, не доказанным work profile. Метка Knox не системная детекция.
Полный мастер, системные app-link настройки, групповые правила и банки ещё впереди.

## Порция 1 — 0.3.0: введение в настройку

Первый launcher старт показывает SetupScreen, карточку текущей роли Android,
количество CrossProfileApps targets, инструкции одинакового APK/клонирования,
кнопку штатного межпрофильного запроса. Samsung определяется через MANUFACTURER,
но это только условие показа инструкции, не обнаружение Secure Folder.
Targets не называются доказанными work/main без данных. После возврата refresh
в onResume. Первый шаг не переключает пресеты и не отмечает маршрут готовым.
Нечувствительные setup-visible и setup-intro-done сохраняются; URL нет.
SEND/VIEW идут в прежний маршрут; warm Intent закрывает экран введения.
Это ещё не полный мастер: далее пока существующий экран настроек.

## Следующие порции

Порция 2 реализована в 0.3.1 для системного share: TransferScreen с фиксированным
именем Ozon/Wildberries и выбранным назначением Secure Folder. Имя не извлекается
из входящего текста, URL не отображается и очищается после запроса chooser.
Экран остаётся после возврата, без retry. При rotation/process death исчезает,
доставка не восстанавливается. В compact это пока backdrop в dialog-окне,
в обычном режиме полноэкранный. Результат chooser не выдаётся за ACK.

2. Экран передачи с именем целевого приложения и выбранным пространством под
   системным chooser, состояния отмены/ошибки/UNKNOWN_OUTCOME без retry.
3. Полный мастер: ручная метка Knox, основное пространство назначения,
   пресеты с просмотром изменений, системные настройки веб-ссылок и тест маршрута.
4. Приложения: поиск/групповой выбор, массовый режим и назначение, отдельная
   политика банков; обычный интерфейс без постоянных checkbox и россыпи toggles.
5. Просмотр/сохранение отчёта через SAF, безопасный процессный ring buffer;
   удаление неиспользуемого TLS tooling и зависимостей по фактическим ссылкам.
6. Т-Банк: 8 доменов со скриншота, проверить package и оплату/возврат из Ozon
   в обеих копиях. Не добавлять банки к магазинному auto-open и не хранить URL.

Отдельная необходимая задача перед обычным распространением — постоянный ключ
подписи в защищённых CI secrets, без перезаписи существующих ключей. Пока ключ
временный, очередной APK не объявляется обновлением с сохранением данных.
