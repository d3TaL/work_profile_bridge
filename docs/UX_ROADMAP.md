# Порционный UX выпуск

## Порция 1 — 0.3.0: введение в настройку

Первый launcher старт показывает SetupScreen, карточку текущей роли Android,
количество CrossProfileApps targets, инструкции одинакового APK/клонирования,
кнопку штатного межпрофильного запроса. Samsung определяется через MANUFACTURER,
но это только условие показа инструкции, не обнаружение Secure Folder.
Targets не называются доказанными work/main без данных. После возврата refresh
в onResume. Первый шаг не переключает пресеты и не отмечает маршрут готовым.
Нечувствительные setup-visible и setup-intro-done сохраняются; URL нет.
SEND/VIEW идут в прежний маршрут; warm Intent закрывает экран введения.
Это ещё не полный мастер: далее пока существующий экран настроек.

## Следующие порции

Порция 2 реализована в 0.3.1 для системного share: TransferScreen с фиксированным
именем Ozon/Wildberries и выбранным назначением Secure Folder. Имя не извлекается
из входящего текста, URL не отображается и очищается после запроса chooser.
Экран остаётся после возврата, без retry. При rotation/process death исчезает,
доставка не восстанавливается. В compact это пока backdrop в dialog-окне,
в обычном режиме полноэкранный. Результат chooser не выдаётся за ACK.

2. Экран передачи с именем целевого приложения и выбранным пространством под
   системным chooser, состояния отмены/ошибки/UNKNOWN_OUTCOME без retry.
3. Полный мастер: ручная метка Knox, основное пространство назначения,
   пресеты с просмотром изменений, системные настройки веб-ссылок и тест маршрута.
4. Приложения: поиск/групповой выбор, массовый режим и назначение, отдельная
   политика банков; обычный интерфейс без постоянных checkbox и россыпи toggles.
5. Просмотр/сохранение отчёта через SAF, безопасный процессный ring buffer;
   удаление неиспользуемого TLS tooling и зависимостей по фактическим ссылкам.
6. Т-Банк: 8 доменов со скриншота, проверить package и оплату/возврат из Ozon
   в обеих копиях. Не добавлять банки к магазинному auto-open и не хранить URL.

Отдельная необходимая задача перед обычным распространением — постоянный ключ
подписи в защищённых CI secrets, без перезаписи существующих ключей. Пока ключ
временный, очередной APK не объявляется обновлением с сохранением данных.
