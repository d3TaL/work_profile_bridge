# Разработка и ручная проверка

Стек: AGP 9.4.1 (built-in Kotlin), Kotlin/JVM и Compose compiler 2.4.21, Gradle 9.8.1, JDK 17, Compose BOM 2026.09.00. Версии взяты из ранее проверенной конфигурации проекта и закреплены в каталоге. Room/DataStore пока не добавлялись: постоянные правила/пары ещё не реализованы.

Команды сборки приведены в README. Wrapper содержит SHA-256 дистрибутива. Запрещено отключать проверки TLS/зависимостей ради сборки. Зависимости фиксируются lockfiles и verification metadata. Факт выполнения проверок — только в VALIDATION.md.

## Проверка TLS между пространствами

1. Установить одинаковый APK в основной профиль, work profile и Secure Folder по необходимости.
2. Во внутренней копии нажать «Запустить TLS-сессию». Дождаться кода PLB2. Первичная генерация ключа идёт вне main thread.
3. Перенести весь код вручную во внешнюю копию. Поле read-only допускает системное выделение текста; автоматического clipboard relay нет. Политика Knox может запретить перенос через clipboard. Многооконный режим облегчает тест.
4. До 120 секунд нажать «Проверить TLS». Не переписывать pin вручную отдельно от кода. Успех означает принятие pin и токена, а не запуск банка.
5. Повторить тест с разблокированной/заблокированной папкой, при сворачивании, включённом VPN и отключённом work profile. Записать результат в COMPATIBILITY.md.
6. Отдельно проверить локальное открытие публичного HTTPS URL внутри нужного пространства и открытие копии через CrossProfileApps. Банковские URL с токенами пока не использовать.

Сессия работает в обычном процессе, без FGS, wakelock и автоперезапуска. Фоновая доступность не гарантируется. Не проверено: Samsung KeyStore/Conscrypt TLS с этим ключом, фон и блокировка Secure Folder на физическом устройстве.

## Skills

Применены официальные android-intent-security и android-permissions-security из Google android/skills, commit 5bda39f154fb859a08d45e2392f3568e049f83fb. Инструкции прочитаны как внешние материалы, не устанавливались в профиль пользователя. Они применяются к Kotlin/Android-коду; отдельный skill JetBrains для KMP-миграции здесь не используется.

## Эффективность

Блокирующая сеть, генерация ключей и поиск обработчиков работают вне main thread. UI собирает StateFlow с lifecycle. Нет непрерывных сетевых запросов, рекламы и аналитики. R8 и resource shrinking включены для Release. Скорость и расход батареи не измерены; benchmark и baseline profile требуют следующего этапа.
