# Иконки приложений

По запросу владельца локальные WebP иконки загружены из карточек RuStore.
Источник каждой: https://www.rustore.ru/catalog/app/<packageName>, package
совпадает с именем app_<packageName с заменой точек на подчёркивания> в drawable.
Список: Ozon, Wildberries, AliExpress, Avito, Яндекс Карты, Яндекс Диск и
14 банков из BankLinks.banks. Бренды и изображения
принадлежат соответствующим правообладателям; используются для идентификации
приложений, не как знак партнёрства или проверки установленного APK.
APK содержит изображения, runtime HTTP-запросов для UI нет.

Иконки, добавленные в 0.6.2 (2026-11-03), взяты из og:image карточек RuStore
(для Avito — со страницы истории версий той же карточки), исходники 512×512,
уменьшены до 192×192 WebP без метаданных. У AliExpress в RuStore в этот момент
была сезонная иконка «11.11»; при следующем обновлении иконок её стоит заменить.
