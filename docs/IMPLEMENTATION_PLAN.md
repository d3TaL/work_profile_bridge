# Этапы

1. Восстановить и повторно проверить исходники после очистки. Не использовать старую аттестацию сборки для нового APK.
2. Проверить TLS 1.3 probe и AndroidKeyStore identity на основном Samsung. Отдельно pin failure и ограничения профилей.
3. Сначала подтвердить разрешённый канал передачи между профилями: Android 17 запрещает межпрофильный loopback по умолчанию; приоритет для work profile — системные API и политика DPC. Для Secure Folder допустимо явно сообщить отсутствие поддерживаемого пути. Для подтверждённого транспорта спроектировать постоянное сопряжение: два подтверждённых endpoint, отзыв, шифрованное локальное хранение credentials, переустановка и ротация ключа. Не объявлять временный PLB2 код готовым постоянным доверием.
4. Реализовать URL protocol, независимую политику получателя, TTL, дедупликацию и UNKNOWN_OUTCOME. Только после этого включать передачу настоящих URL.
5. Добавить уведомления/ручное открытие и проверенный законный background mode. Исследовать CrossProfileApps/DPC и опциональный Shizuku.
6. Подключить Ozon и названные владельцем банки по реальным пакетам/поддерживаемым ссылкам. Проверить callback отдельно. Расширить тесты Android 11–17.

Открыто: модели/прошивки, администратор work profile, доступность Shizuku, банк/URL presets, release signing, долгосрочный listener и канал сообщения об уязвимостях.
