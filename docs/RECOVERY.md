# Восстановление 2026-10-17

Автоматическая очистка рабочей среды удалила предыдущие исходники, SDK и сборки. Предыдущий архив не удалось получить из доступного контекста файлов. Код восстановлен из сообщений этой беседы, а не из найденного оригинала.

Сохранены архитектурные границы: один APK в нескольких пространствах, отдельное Kotlin/JVM-ядро, строгая обработка ссылок, отсутствие команд в диагностическом протоколе, явный выбор приложения и локальный пользовательский жест.

Вместо старого plaintext ping реализован отдельный TLS 1.3 ping. Старые тесты доменной логики восстановлены по поведению, сетевые тесты заменены тестами TLS, включая неверный pin и запрет downgrade. Полные старые формулировки документации, контрольные суммы и подпись APK не восстановлены. Исходники и результаты 0.1.1 должны оцениваться заново.

Новый debug APK имеет новую подпись. Если 0.1.0 уже установлен, обновление поверх него может быть отклонено; для диагностической установки потребуется удалить старую копию. Не применять этот способ к установленным банковским приложениям.

Скачанный архив следует сохранить у себя и поместить исходники в свой git-репозиторий. Резервная копия исходников не включает production signing keys.
