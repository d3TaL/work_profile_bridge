# ADR-001: несколько транспортов

Принято как архитектурное направление. Один APK, независимые экземпляры, отдельно routing/delivery/launch. CrossProfileApps/DPC исследуется для work profile; loopback остаётся диагностикой старых версий и OEM-поведения, а не выбранным транспортом Secure Folder на Android 17. Android 17 запрещает межпрофильный loopback по умолчанию. Поддерживаемый публичный путь Secure Folder пока не подтверждён. Shizuku необязателен. Не обещать одинаковую доступность на всех прошивках. Облачный relay и root не используем.
