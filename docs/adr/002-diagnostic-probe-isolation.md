# ADR-002: изоляция диагностики

Диагностический протокол не содержит URL, package или команд. Успех ping — только проверка канала. Сетевые и lifecycle ограничения не обходятся. Старый PLB1 plaintext test не восстановлен в приложение; 0.1.1 использует отдельный PLB2 TLS probe. Реальный URL Transport создаётся отдельно.
